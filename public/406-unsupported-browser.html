It's one of the standard HTTP status codes a server sends back to a browser. 406 means the server can't produce a response in a format the browser said it can accept. Rails apps generated from Rails 7.1 onward ship a controller-level guard called `allow_browser versions: :modern` (normally added to app/controllers/application_controller.rb by the `rails new` generator) that checks the requesting browser's user-agent against a minimum set of modern-browser features (e.g. CSS nesting, import maps, WebP support) and automatically returns 406 with THIS exact file when the browser is too old to support them — hence the filename `406-unsupported-browser.html` rather than a plain `406.html`. Normal Rails pages (like app/views/*.html.erb) require the whole Rails application to be loaded and working — the router, the controllers, the database connection, etc. The `allow_browser` guard described above is, by design, meant to short-circuit BEFORE any real view rendering, since an unsupported browser might not even be able to correctly render a modern ERB-templated page (that's the whole problem being guarded against).
