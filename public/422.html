WHY IS IT A STATIC FILE INSTEAD OF A NORMAL RAILS VIEW? Normal Rails pages (like app/views/*.html.erb) require the whole Rails application to be loaded and working — the router, the controllers, the database connection, etc. CSRF rejection happens in a low-level middleware step before a controller action's own view-rendering logic runs, so Rails falls back to this plain file in public/ instead, keeping it reliable regardless of what state the rest of the request pipeline is in. WHAT DOES "422 UNPROCESSABLE ENTITY" MEAN? It's one of the standard HTTP status codes a server sends back to a browser. 422 means the server understood the request and the data was well-formed, but it still couldn't be processed for some other reason.
